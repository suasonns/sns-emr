## Stable test ID pattern

`HOPE-{ITEM}-{TIMEPOINT}-{SCENARIO}`

Example: `HOPE-J2051C-ADM-VALUE-2-TRIGGERS-SFV`

## Execution statuses

- Not written
- Written
- Executed
- Passed
- Failed
- Blocked

A test is not PASS until it has been executed and evidence is recorded.
