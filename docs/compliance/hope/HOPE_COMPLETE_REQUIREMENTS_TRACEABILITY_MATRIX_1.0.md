# HOPE Complete Requirements Traceability Matrix

Document ID: HOPE-TRACE-001  
Version: 1.0  
Status: Draft

The companion CSV is canonical for row-level tracing.

## Completion rule

An item remains `UNVERIFIED` until official concept, value set, record type,
timepoint, look-back, sources, skips, triggers, timing, corrections, export,
technical edits, SNS ownership, UI/API/storage/validation/export/audit mappings,
tests, historical impact, evidence, review, and owner decision are resolved.

## Allowed statuses

- PASS
- FAIL
- PARTIAL
- NOT IMPLEMENTED
- NOT APPLICABLE
- UNVERIFIED
