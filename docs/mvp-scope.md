# Hospice EMR MVP Scope

## 1. Purpose

This document defines the Minimum Viable Product (MVP) scope for the hospice EMR system.

The MVP focuses on core clinical documentation required to support hospice care while maintaining compliance and patient safety.

---

## 2. Included Features (MVP)

The MVP shall include:

### 2.1 User Management
- Secure user login
- Role-based access control

### 2.2 Patient Management
- Patient demographics
- Medical Record Number (MRN)
- Patient status (active, discharged, deceased)

### 2.3 Hospice Admission
- Admission documentation
- Eligibility certification tracking

### 2.4 Clinical Visits
- Nursing visits (RN, LVN)
- NP and physician visits
- Discipline-specific visit notes

### 2.5 Clinical Documentation
- Draft and finalized notes
- Date, time, and author tracking
- Amendments to finalized records

### 2.6 Medication Management
- Active medication list
- Medication history

---

## 3. Excluded Features (Post-MVP)

The following features are intentionally excluded from the MVP:

- Billing and claims
- Medicare electronic submissions
- Pharmacy integrations
- Laboratory integrations
- Scheduling automation
- Mobile applications
- Reporting dashboards
- AI or decision support tools

---

## 4. Success Criteria

The MVP is considered successful if:
- Core hospice workflows can be completed end-to-end
- Clinical documentation is accurate and auditable
- User access is properly restricted by role
