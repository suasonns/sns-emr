## Roles & Tenant Authority Model (LOCKED)

Owner Super User:
- Platform-wide governance only
- Never bypasses tenant isolation

Tenant Super User (Optional / Subscription-Gated):
- Tenant-scoped only
- Cannot access other tenants
- Cannot browse files without patient context

Tenant Admin:
- Tenant-scoped
- Admin dashboards only
- No global file browsing

Clinical Staff:
- Assigned-patient access only
- Files visible only via patient charts
