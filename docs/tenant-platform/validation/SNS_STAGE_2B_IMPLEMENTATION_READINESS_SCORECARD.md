## Status definitions

- **READY:** Evidence, authority, decision, design, and tests are sufficient for the scoped implementation.
- **PARTIAL:** Foundation exists, but noncritical design or evidence remains incomplete.
- **BLOCKED:** A critical approval, safety condition, authority boundary, branch condition, or technical contract is missing.
- **NOT VERIFIED:** Evidence has not been produced.
- **NOT APPLICABLE:** Domain does not apply to the scoped phase.

## Gate severity

- **Critical:** Blocks Stage 2B.
- **High:** Blocks the affected implementation phase.
- **Medium:** Must be resolved before production release.
- **Low:** Documentation or optimization follow-up.
